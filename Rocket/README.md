🧠 Project Overview

This project showcases a 3D rocket model created in Blender and integrated into a React app using React Three Fiber.

The rocket is displayed in a simple, sky-blue scene — minimal, clean, and focused purely on rendering the model.

🚀 Tech Stack

React Three Fiber for 3D rendering

Three.js under the hood

Blender for modeling and baking

🖼️ Features

Lightweight and responsive scene

Interactive camera controls via OrbitControls

Smooth rendering with React integration

🧩 Notes

Nothing fancy here — just a small project to experiment with Blender models and React Three Fiber.
